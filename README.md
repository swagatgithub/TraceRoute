# TraceRoute

TraceRoute is a modern Android application built using Jetpack Compose that allows users to search for a source and destination location, visualize the route on Google Maps, draw a polyline between locations, and animate a moving marker along the generated path.

## Features

* Google Maps route visualization
* Source & destination search with autocomplete
* Polyline drawing between locations
* Smooth moving marker animation
* Dynamic route updates
* Stable map interactions during animation
* MVVM architecture with Hilt

## Tech Stack

* Kotlin
* Jetpack Compose
* MVVM Architecture
* Hilt
* Retrofit + OkHttp
* Google Maps SDK
* Google Places API
* Google Directions API
* Coroutines + StateFlow
